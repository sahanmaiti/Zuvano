## 3. Decisions locked today

- iPhone-only MVP, SwiftUI, iOS 26.0 deploy minimum, iOS 27 for dev/test
- Apple frameworks only, no third-party UI stack
- Not a chatbot, archive, memory product, or background monitor
- No auto-execution: user creates each Action Draft explicitly
- Calendar and Reminders are the native outputs
- Liquid Glass on functional chrome, not draft content
- Accessibility is part of the product, not a later pass
