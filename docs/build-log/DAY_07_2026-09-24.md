## 1. What was implemented

### Privacy / persistence

- **`ZuvanoModelContainer`**: SwiftData store under Application Support `ZuvanoStore`, with `isExcludedFromBackup` on that directory (aligns locked Home copy with Data Model §12).
- **`ZuvanoApp`**: uses the production container factory; model container `fatalError` no longer embeds error details (TD-19).

### Regression tests

- **`PurgeTests`**: verifies `purgeIntake` removes extracted text, drafts, and temp image files; smoke test that production `ModelContainer` configuration builds.

### Visual / accessibility hardening (Action Review)

- **Batch Select**: replaced `List(selection:)` trailing checkmarks with **leading** selection controls so trailing checkmarks stay reserved for **Created** (UI spec §54.5).
- **VoiceOver**: custom accessibility actions registered only when applicable (Create, Skip, Restore, Retry, Dismiss failure).
- **Touch targets**: 44 pt minimum on row recovery controls (Restore, Retry, Dismiss, Try Again, Open Settings) and permission banner Settings.
- **Announcements**: post-create VoiceOver announcements use generic Calendar/Reminders copy without draft titles.

### QA / verification

- Full **`ZuvanoTests`** suite on iPhone 18 Pro simulator (56 tests).
- **Release** configuration build for simulator succeeded.
- **Release archive** for generic iOS device failed: App Group entitlements require a development signing identity (not configured in this environment).

**Not verified in this session:** physical iPhone, Share Sheet E2E, Light/Dark/Dynamic Type/VoiceOver/Reduce Motion manual matrix, backup exclusion on device manifests.

## 3. Architecture / product decisions

- **Backup exclusion** is best-effort (`try?` on resource values). If Application Support is unavailable, fall back to default SwiftData location (documented limitation).
- **No frozen doc changes.** Home privacy sentence unchanged; exclusion makes it more accurate.
- **RC archive** blocked on signing, not on compile. Simulator Release build is the verified RC artifact here.
